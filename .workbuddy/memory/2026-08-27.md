## 修复：标题栏职业显示成目标名称
根因：NPCBot 是 creature，客户端 `UnitClass` 对 creature 的第一个返回值（本地化职业名）不可靠（返回单位名称），导致 title 方括号内显示成目标名。
修复：`GetUnitDisplayInfo` 改用 `select(2, UnitClass(unit))` 取英文 class token，配合新增 `CLASS_LOCALIZED_NAMES` 映射表（WARRIOR=战士 … DEATHKNIGHT=死亡骑士）得到本地化职业名；职业颜色仍用 `RAID_CLASS_COLORS[classToken]`。参考文件：`netherbot.lua`（用户提供）也是用第二个返回值判断 bot 职业。
