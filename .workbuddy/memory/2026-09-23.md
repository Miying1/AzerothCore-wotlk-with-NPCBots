## 全量换嘲 debuff 持续时间 → 层数复核（2026-09-23 第三轮，权威 SpellDuration.csv）
用户提供 `G:\wow\dbc_csv\SpellDuration.csv` 权威数据（ID,Duration,PerLevel,MaxDuration 三列，Duration 单位毫秒）。
**修正此前第69行凭记忆的 DurationIndex 字典（大面积错误）**。权威值：
- ID=1:10s、3:60s、8:15s、9:30s、18:20s、22:45s、25:180s、27:3s、28:5s、32:6s、35:4s、64:40s、572:100s。
- 旧错误字典「18=6s、25=4s、28=10s、29=30s、31=15s」全部作废。

**核心判据**：换嘲阈值必须满足「叠层间隔 I × 层数 N ≤ debuff 持续时间 D」——即旧坦 debuff 须在下一次轮到它接怪前自然消失，否则层数累积。
分两类：
1. **D ≥ I×N（真叠层换嘲）**：层数按官方标准。脓肠(N=9,官方)、教授(N=2,官方)、柯洛刚恩25(N=2,官方2层)、戈莫克(N=3,官方3层) 均正确。
2. **D << I（刷新式，永远叠不到2层）**：必须改 1 层或删除。本轮修正：
   - 血腥女王疯狂斩杀 71623：D=15s < I=20~24s → **2层改1层**
   - 破钢者熔化冲压 61903/63493：D=4s < I=15~20s → **2层改1层**
   - 纳罗拉克裂伤 42389：脚本 HasAura 判断刷新式(60s标记) → **2层改1层**
   - 纳罗拉克撕裂 42397：D=5s < I=6~21s → **2层改1层**
3. **非换嘲机制（随机点名）→ 删除**：
   - 墨吉姆静电瓦解 61912/63494：实为破钢者(Steelbreaker)技能 EVENT_STATIC_DISRUPTION，且 SelectTarget(Random) 随机点名远程+5码溅射(脚本注释明确"让易伤远离近战/坦克堆")，双重错误 → **删除**
   - 威札斯无面者印记 63276：脚本 SelectTarget(Random) 优先15码外远程，Aura=226 周期偷血回血BOSS，非对坦 → **删除**
4. **注释修正（层数不变）**：
   - 教授畸变瘟疫 72451：注释「持续4秒」错误 → 实际 D=180s(DI=25)，全团DOT每层x3，官方2层换嘲；阶段切换由 72618 Mutated Plague Clear 清除。
   - 艾尔加隆警戒冲击 64392/64679：D=5s(DI=28)<<施放间隔15.5s，标「可叠加」实为刷新式，1层命中即换(本质是+99%暗影易伤下量子打击双倍伤害的真空期，非叠层)。

**最终各副本换嘲结论**：
- ICC(631)：巫妖王69410(1)、萨鲁法尔72410(1)、辛德拉苟莎69649(1)、脓肠72219(9)、教授72451(2)、血腥女王71623(1)。
