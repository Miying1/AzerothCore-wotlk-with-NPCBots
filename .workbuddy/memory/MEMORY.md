# 项目长期约定

- `outputs/` 下交付给用户的报告、设计文档和资源清单默认使用清晰的中文文件名；文档内部交叉引用必须同步使用中文路径。源码、脚本、SQL迁移等受工程命名规范约束的文件不因此改为中文。
- 五人英雄裂隙源码统一组织在 `src/server/scripts/HeroicDungeonRift/`：根目录放共享代码、配置、传送和管理代码；普通源码文件及 `AddSC_` 注册函数使用 `rift_` 前缀，Boss脚本使用 `boss_rift_` 前缀，模块总入口为 `AddHeroicDungeonRiftScripts()`；每个目标副本建立独立子目录，副本适配代码和该副本所有Boss脚本均放入对应子目录，不散落到根目录或原版副本脚本目录。
- 五人英雄裂隙 Entry 分配（不可与其它区间重叠）：入口NPC 100000；首批16个Boss(boss_id 1–16) T1/T2/T3 为 100001–100048；新增Sheet2的31个Boss(boss_id 17–47) T1/T2/T3 为 100200–100292（公式 `T1 = 100200 + (boss_id-17)*3`）；召唤物 100100–100110（首批）+ 100300–100312（新增）；出口门 100500–100502。主Boss 83级、召唤物 82级；同一Boss的T1/T2/T3共用同一 `boss_rift_*` 脚本，双Boss同伴用 `npc_rift_*` 召唤物Entry协作。
- 构建环境约束：amd64 版 MSBuild.exe 启动即崩溃（0xC0000005 访问冲突，仅 amd64 受影响、x86 版正常），导致 VS 解决方案生成器（`build/`、.slnx）不可用。构建必须用 Ninja + VS2026 MSVC（`build-ninja/` 目录）。工具链：MSVC 14.51.36231（VS2026 Community 18.8）、CMake 4.3.1（VS 自带）+ 4.4.2（独立安装，`C:\Program Files\CMake\bin`，含 cmake-gui.exe）、MySQL 8.0.46（`D:/Program Files (x86)/mysql`）、Boost 1.91.0（`C:/local/boost_1_91_0`）、Windows SDK 10.0.22621.0。重新配置方法：用 PowerShell 工具执行 `Launch-VsDevShell.ps1 -Arch amd64 -HostArch amd64`（路径 `Common7\Tools\`）设置 vcvars 环境后，再运行 `cmake -S <src> -B build-ninja`（不带 `-A`，复用缓存）。
