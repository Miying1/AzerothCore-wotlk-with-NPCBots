## 0. 总览与通用约定

### 0.1 专精与角色

| 常量 | 值 | 定位 |
|---|---|---|
| `BOT_SPEC_PRIEST_DISCIPLINE` | 13 | 戒律：盾+吸收+减伤，副治疗 |
| `BOT_SPEC_PRIEST_HOLY` | 14 | 神圣：群刷+单体高效治疗 |
| `BOT_SPEC_PRIEST_SHADOW` | 15 | 暗影：DoT+填充输出 |

角色位（`botcommon.h`）：`BOT_ROLE_HEAL`（0x8）、`BOT_ROLE_DPS`（0x4）、`BOT_ROLE_DPS|BOT_ROLE_HEAL` 混合。

### 0.2 三系战斗循环总原则（PVE）

```
治疗系：保持增益 → 危险目标先减伤（盾/守护之魂/痛苦压制）→ 群刷（团血）
        → 单体补 DoT（恢复/愈合祷言）→ 填充（快速治疗/强效治疗术）→ 空闲输出（惩击）

暗影系：起手挂 DoT（吸血鬼之触 → 痛 → 噬灵疫病）→ 卡 CD 心灵震爆
        → 心灵鞭笞填充 → 斩杀期死亡 → 蓝量/爆发期暗影魔

共同：驱散（魔法/疾病）、打断（沉默/心灵恐慌）、控制（束缚亡灵/心灵尖啸）
```

### 0.3 已确认的实现缺陷（三系共有）

| 编号 | 缺陷 | 影响 |
|---|---|---|
| G1 | 戒律系 9 个天赋被动等级门槛错误写成 `>=70` | 70 级以下戒律牧核心天赋全失效 |
| G2 | 从未主动刷新「虚弱灵魂」 | Renewed Hope / Borrowed Time 全程空转 |
| G3 | `_heals` 为初始化快照，不随增益更新 | 治疗决策失准 |
| G4 | `Smite` 被限制 `< level 20` | 20 级后惩击永不使用，圣光涌动空转 |
| G5 | 缺 `Binding Heal` / `Mana Burn` / `Lightwell` | 功能缺失（文件头 TODO） |
| G6 | `Misery` 团队 3% 法术易伤未实现 | 团队收益缺失 |
| G7 | `GLYPH_SW_PAIN` 被注释未启用 | 暗牧少 10% 痛点暴击 |

### 1.2 主动技能与天赋应用

**核心技能池**：真言术：盾（17）、苦修（47540）、快速治疗（2061）、强效治疗术（2060）、恢复（139）、愈合祷言（33076）、能量灌注（10060）、痛苦压制（33206）、心灵专注（14751）、群体驱散（32375）、神圣赞美诗（64843）。

**缺失/不合理的应用**：

1. **虚弱灵魂联动缺失（G2，最高优先级）**
   - `Renewed Hope`（57472）需要目标带「虚弱灵魂」才能给 快速治疗/强效治疗术/苦修 提供 4% 暴击。
   - `Borrowed Time`（52800）需要施放真言术盾后，下个法术获得 40% 法强急速。
   - 当前 `ShieldGroup` 仅在目标「正在被攻击」时套盾，坦克满血时不套 → 两者长期空转。
   - **修正**：在战斗中为 `IsTank(target)` 或 `IsPointedHealTarget(target)` 周期性套盾（间隔 ≥ 虚弱灵魂持续时间）。同时在坦克身上保持盾以激活天赋。

2. **盾的判定重复**
   - `ShieldGroup` / `ShieldTarget` / `doDefend` 三处都会套盾，易连续施放浪费 GCD。
   - **修正**：统一到 `ShieldGroup`，`doDefend` 只处理自己且加 `!me->HasAura(WEAKENED_SOUL_DEBUFF)` 判定。

3. **苦修（Penance）使用逻辑**
   - 当前仅视为治疗技能（`hp <= 80 && Rand()<90`）。戒律输出形态下苦修也是 DPS 技能（造成神圣伤害）。
   - **修正**：当 `HasRole(DPS) && !HasRole(HEAL)` 时，苦修进入输出循环（放在心灵震爆之前）。

4. **能量灌注（10060）**
   - 当前 `CheckPowerInfusion` 已实现，锁定主手蓝量 <70% 的法系职业，逻辑基本正确。
   - **补充**：优先给「当前蓝量百分比最低的治疗者」，并对暗影/痛苦术等爆发职业加权。

5. **痛苦压制（33206）与守护之魂（47788）**
   - 守护之魂属神圣系（47788），痛苦压制属戒律系。两者都是「保命大招」，应在坦克血量 <35% 且掉血速率快时无 GCD 插入（当前已实现，保留）。

6. **群体驱散（32375）**
   - 当前 `CheckDispel` 用 `GetSpec()==DISCIPLINE` 判定可用。正确，但应优先对「同时有多个可驱散减益的敌方目标」使用而非单体。

### 1.3 戒律系战斗逻辑流程

```
[战斗开始]
  ├─ 保持团队增益：真言术：韧、神圣之灵、暗影防护、心灵之火
  ├─ 坦克/被点名目标：真言术：盾（维持虚弱灵魂）→ 触发 Borrowed Time
  ├─ 愈合祷言：坦克/被攻击单位（<85% 血）
  ├─ 单体治疗优先级：
  │     血量<35% → 痛苦压制 / 守护之魂（无GCD插入）
  │     血量<80% → 苦修（快速高效）
  │     DoT缺失 → 恢复
  │     填充 → 强效治疗术 > 快速治疗
  ├─ 群刷：神圣赞美诗（大量团血）> 治疗祷言
  ├─ 能量灌注：给蓝量最低的队友（非坦克）
  ├─ 驱散：对敌方驱散魔法/群体驱散（吸收盾优先群体驱散）
  └─ 空闲/输出位：惩击 + 神圣之火 + 苦修（搭配圣光涌动瞬发）
```

### 2.2 主动技能与天赋应用

**核心技能池**：治疗之环（34861）、治疗祷言（596）、恢复（139）、强效治疗术（2060）、快速治疗（2061）、神圣赞美诗（64843）、愈合祷言（33076）、守护之魂（47788）、绝望祷言（19236）、惩击（585）、神圣之火（14914）。

**缺失/不合理应用**：

1. **惩击被禁用（G4）**
   - 当前 `IsSpellReady(SMITE_1) && me->GetLevel() < 20`，20 级后完全不用惩击。
   - 后果：`SURGE_OF_LIGHT`（圣光涌动：爆击触发下一次惩击/快速治疗瞬发免蓝）完全没有出口。
   - **修正**：移除等级限制；并新增「圣光涌动触发时优先瞬发惩击」逻辑。

2. **治疗之环（34861）使用条件过严**
   - 当前 `MassGroupHeal` 要求 `LHPcount3 > 1`（至少 2 人 <85% 血）。神圣系核心群刷技能，应放宽到「≥1 人 <80% 且 15 码内有第二个低血单位」。
   - **修正**：调整阈值使 5 人小队场景下能正常触发。

3. **神圣赞美诗（64843）**
   - 触发条件 `LHPcount1 > 2`（≥3 人 <80%）。合理，但 `Rand() > (65 + 40*Raid)` 的概率门控在普通副本下 65%，可能导致 CD 空转。可接受，保留。

4. **守护之魂（47788）**
   - 已在 `HealTarget` 首段无 GCD 处理，逻辑合理（血量<50% 或预测致死）。
   - **补充**：应对 `IsTank(target)` 的判定加权，避免误用在普通 DPS 身上。

5. **绝望祷言（19236）**
   - 当前仅对自己，`hp<=50 && Rand()<45`。合理。

6. **Body and Soul / Serendipity**
   - `BODY_AND_SOUL1`（全心全意）让盾后目标加速；`SERENDIPITY`（好运）让快速治疗刷新增益，减少强效治疗术/治疗祷言施法时间。
   - **修正**：当前实现「同时移除 Serendipity」，但未对快速治疗的使用加权。应在坦克需要大治疗时，先用快速治疗堆 Serendipity 再放强效治疗术。

### 3.2 主动技能与天赋应用

**缺失/不合理应用**：

1. **暗言术：痛（SW:Pain）补 Dot 条件过严（最高优先级）**
   - 当前（满级）要求「暗影交织 ≥4 层」才补痛。
   - 后果：Boss 短血量或爆发期 DoT 掉落后长期不补，直接损失 心灵震爆/心灵鞭笞 的 `Twisted Faith`(10%) + `Glyph of Mind Flay`(10%) 加成（依赖 SW:Pain 存在）。
   - **修正**：血量 > 自身最大血量 1.5 倍时直接补，不绑定层数。

2. **心灵鞭笞（Mind Flay）被治疗角色过滤**
   - 当前条件含 `(!HasRole(HEAL) || mytar->GetHealth() < me->GetMaxHealth()/2)`。
   - 后果：混合角色下 MF 被跳过，暗牧填充断档。
   - **修正**：MF 是暗牧基础填充，移除 HEAL 角色耦合。

3. **惩击（Smite）在暗影系完全无用**
   - 暗影系不应使用惩击（正确），但 `SMITE_1` 的 `<20 级` 限制会让 1-20 级暗影形态前的输出缺失。保留即可。

4. **暗影魔（34433）CD 与增益**
   - 当前 `SetSpellCooldown(SHADOWFIEND_1, 180000)`（3 分钟），注释写「5-2 分钟 with Veiled Shadows」，但 `Veiled Shadows`（暗影系减 CD）在 `ApplyClassSpellCooldownMods` 中被注释掉（1452-1453），实际 CD 恒为 180s。
   - **修正**：暗影系启用 Veiled Shadows（暗影魔 CD -2 分钟 → 实际约 3 分钟转好，配合精神分流回蓝）。

5. **噬灵疫病（Devouring Plague）**
   - 当前仅暗影系或 PvP 目标使用。合理，但需确认对「免疫感染机制」的目标跳过（代码已处理）。

6. **消散（47585）**
   - 当前用于：被围攻、低血、低蓝（<35%）。合理。雕文减少 45s CD 已实现。

7. **心灵灼烧（48045）**
   - 当前仅在「目标攻击者 >3」且找到集群 3 目标时使用。合理。

8. **暗言术：灭（SW:Death）**
   - 当前要求 `GetHealthPCT(me) > 50`（反噬安全）。合理。

9. **吸血鬼的拥抱（15286）与 Vampiric Embrace 强化**

### 4.2 虚弱灵魂维持（G2）

```cpp
void MaintainWeakenedSoul(uint32 diff)
{
    if (GetSpec() != BOT_SPEC_PRIEST_DISCIPLINE)
        return;
    if (!IsSpellReady(PW_SHIELD_1, false, diff) || IsCasting())
        return;
    // 坦克保持盾，激活 Renewed Hope / Borrowed Time
    for (Unit* member : BotMgr::GetAllGroupMembers(gr))
    {
        if (!IsTank(member) || member->HasAura(WEAKENED_SOUL_DEBUFF))
            continue;
        if (ShieldTarget(member, diff))
            return;
    }
}
```
