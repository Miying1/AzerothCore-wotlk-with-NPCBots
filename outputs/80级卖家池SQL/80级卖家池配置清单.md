# 80级内容 mod-ah-seller 池配置清单

## 使用范围

- 数据来源：当前本地 `acore_world.item_template`。
- 生成日期：2026-08-21。
- 所有池均为 **Entry 池**（`pool_type=2`），由 SQL 直接写入符合条件的 `item_id`。
- 所有拍卖统一进入中立拍卖行；模块配置文件仍需设置 `AhSeller.Enable`、`AhSeller.Account` 和 `AhSeller.GUID`。
- 执行顺序：先导入 `modules/mod-ah-seller/data/sql/db-world/mod_ah_seller.sql` 建表，再执行本目录 01~08 SQL。
- 各 SQL 可重复执行：先删除对应池 ID 的旧数据，再重新建立池和池内物品。

## 关键口径说明

### 宝石名称口径

这里将“绿色宝石”和“紫色宝石”按 **宝石颜色** 处理，而不是按物品品质文字直译：

- 绿色：Forest Emerald、Eye of Zul。
- 紫色：Dreadstone、Ametrine。
- 只保留成品：`stackable=1`；原石通常可堆叠 20 个，因此不会进入池子。
- 排除珠宝专业限制：`RequiredSkill=0 AND bonding=0`；因此 Dragon's Eye 等珠宝专业专用物品不会进入第 3 池。

### 第 5 池的数据库现状

当前数据库查询：

```sql
SELECT entry, name, ItemLevel, Quality, stackable, bonding
FROM item_template
WHERE class=0 AND subclass=6
  AND Quality=4
  AND name LIKE 'Scroll of Enchant%';
```

结果为空。因此第 5 池保留为**禁用空池**，不会产生补货日志或拍卖。如果用户原意是“紫色宝石成品（排除珠宝专业限制宝石）”，该需求已经由第 3 池实现；如果原意确实是紫色品质附魔卷轴，后续新增对应物品后再启用 805 池。

### 模块当前实现的注意事项

- `stack_count=1` 对单颗宝石、坐骑和装备是合适的；卷轴和腿部附魔分别使用 5、20。
- `max_count` 表示该池 bot 挂单的堆数上限，不是整个拍卖行市场总库存。
- `price_up_pct` 和 `price_down_pct` 均为 0 才完全关闭热度记录；本清单中的池均启用了浮动。
- 当前首次实现仍存在已知限制：重叠池会按 item entry 重复计数，`stack_count` 超过物品最大堆叠时会截断；本次 SQL 已尽量采用不重叠的筛选条件，且显式设置为实际可用堆叠数。
