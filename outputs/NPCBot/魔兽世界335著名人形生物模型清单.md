## 五、创建自定义模型 BOT 的命令用法

### 5.1 语法

```
.npcbot createnew #名称 #职业 #种族 #模型ID
```

- 指定 `#模型ID` 后**不需要**再填性别/皮肤/脸型/发型/发色/特征，命令会自动跳过外观校验。
- `#种族` 仍必填：它决定种族技能与默认阵营，与模型外观无关。
- 游戏内聊天框带 `.`；worldserver 控制台执行时去掉开头的 `.`。
- 创建完成后需**重启 worldserver**，再用 `.npcbot spawn <entry>` 生成到当前坐标（新条目从 70800 起顺延）。

职业 ID：战士 1、圣骑士 2、猎人 3、盗贼 4、牧师 5、死亡骑士 6、萨满 7、法师 8、术士 9、德鲁伊 11。
种族 ID：人类 1、兽人 2、矮人 3、暗夜精灵 4、亡灵 5、牛头人 6、侏儒 7、巨魔 8、血精灵 10、德莱尼 11。

### 5.2 示例

```
.npcbot createnew 巫妖王 6 1 30721
.npcbot createnew 伊利丹 4 4 21135
.npcbot createnew 凯尔萨斯 8 10 22906
.npcbot createnew 索尔 7 2 27744
.npcbot createnew 珍娜 8 1 30867
.npcbot createnew 提里奥 2 1 25965
.npcbot createnew 萨鲁法尔 1 2 30790
.npcbot createnew 兰娜瑟尔 5 5 31165
.npcbot createnew 奥尔加隆 5 11 28641
```

控制台写法（注意去掉点号）：

```
npcbot createnew 巫妖王 6 1 30721
```

### 5.3 注意事项

1. **模型 ID 必须存在于 `creature_model_info` 表**，否则 bot 创建时会因「模型未定义」直接失败（`Creature::Create` 里 `GetCreatureModelRandomGender` 返回空）。本清单中的模型都来自现有生物模板，本地库已 100% 覆盖，可放心使用。
2. **模型 ID 小于 256 时**，参数会先被前面 5 个 `uint8` 外观参数吃掉，此时必须写全占位：
   ```
   .npcbot createnew 名称 4 10 0 0 0 0 0 0 1 116
   ```
   （倒数第二位是音色 1~3，最后一位才是模型 ID。）
3. **体型不归一**：直接写模板模型时，缩放沿用原职业模型的 `DisplayScale`，换成大体型 Boss 模型可能明显偏大/偏小，攻击距离与视觉体积会不一致。若需要体积一致，参考幻形（变身）方案：运行期 `SetNativeDisplayId` + `SetDisplayId(CalculateBotTransmogScale(...))`，或直接使用模块的「佣兵幻形」功能。
4. **性别/外观数据为空**不影响显示：bot 是 Creature，渲染只看 DisplayId；`creature_template_npcbot_appearance` 缺行只影响名字查询的性别显示与镜像/克隆技能的外观字节。
5. 若模型 ID 对应的 `creature_model_info.DisplayID_Other_Gender` 非 0，加载时有 50% 概率被随机换成另一性别模型；遇到这种情况，可先清空该行的 `DisplayID_Other_Gender` 再创建。

### 5.4 查询某个 NPC 的模型 ID（自定义名字时用）

```sql
SELECT ct.entry, ct.name, ct.subname, m.CreatureDisplayID
FROM acore_world.creature_template ct
JOIN acore_world.creature_template_model m ON m.CreatureID = ct.entry AND m.Idx = 0
WHERE ct.name LIKE '%巫妖王%';
```
