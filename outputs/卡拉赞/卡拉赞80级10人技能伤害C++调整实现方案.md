## 执行摘要

**目标**：在上游文档（v1.3）只做 `creature_template` 等级/Modifier 增强、**法术伤害保持 70 级 DBC 原值不变**的基础上，通过**纯 C++ 脚本层**把卡拉赞 Boss 与召唤物的直接法术伤害、DOT 周期伤害，提升到 **ICC 10 人普通（83 级）Boss 量级**，并**按 Boss 实际强弱与技能风格逐一设定合理倍率**（严禁统一倍率）。

**核心结论**：采用**两张通用脚本类 + 一张静态倍率表 + `spell_script_names` 表绑定**的方案，对 75 个法术 ID 做差异化缩放（Boss/召唤物 32 + 精英 42 + 埃兰暴风雪 1）：

- **直接伤害**（`SpellScript::OnHit` → `SetHitDamage`）：51 个纯直伤 + 10 个"直伤+DOT"，倍率 **2.0×~8.5×**。
- **DOT 每跳**（`AuraScript::OnEffectApply` → `SetAmount`）：14 个纯 DOT + 10 个"直伤+DOT"，倍率 **2.0×~4.0×**。
- **治疗**（朱丽叶·永恒爱恋 30878）：**不缩放**（`SetHitDamage` 不作用于治疗，且原治疗量已足够）。
- **武器伤害型技能**：走 §6.3 的 `DamageModifier` 通道，**不在本次 C++ 缩放范围**。
- **机制/百分比/控制技能**：不缩放。

**关键事实**：

- 卡拉赞 Boss 法术的 `EffectRealPointsPerLevel` 均为 0，直接法术伤害是 DBC 固定值，`DamageModifier` 与等级**都不影响**它——所以必须用脚本在命中点重写伤害。
- 部分"技能"在 DBC 里是**触发/召唤母体**，真正伤害在**子法术**上：奥术飞弹(29955→子 29956)、地狱火灼烧(30859→子 30860)、虚空吐息(38523→子 38524)、虚空领域(37063→召唤单位 16697)。缩放要落在**子法术**上。
- 脚本与法术的绑定走 `spell_script_names` 表（`spell_id, ScriptName`），**同一脚本名可绑定多个法术**，这是本方案"一个通用脚本类覆盖 75 个法术"的落点。

## 3. 技术机制

### 3.1 直接伤害：`SpellScript::OnHit` + `SetHitDamage`

在 `OnHit` 钩子（每个目标命中一次）里用 `SetHitDamage(GetHitDamage() × 倍率)` 重写总伤害。项目内已有同款范例：`spell_mirkblood_exsanguinate::CalculateDamage`（`OnHit += SpellHitFn(...)` + `SetHitDamage(...)`）。对多目标 AOE（暗影新星、奥术爆炸等）按目标逐个命中触发，天然逐目标生效。

### 3.2 DOT：`AuraScript::OnEffectApply` + `SetAmount`

周期伤害（`SPELL_AURA_PERIODIC_DAMAGE`）的每跳伤害在光环**首次真实应用**时用 `SetAmount(原值 × 倍率)` 重设一次即可（`SetAmount` 会置 `m_canBeRecalculated = false`，后续刷新不会回写原值）。项目内范例：`spell_nether_portal_perseverence`（`OnEffectApply` + `const_cast<AuraEffect*>(aurEff)->SetAmount(...)`）。

> **为什么不用 `OnEffectPeriodic`**：该钩子每跳触发，若直接乘当前值会指数叠加（1750→5250→15750…）。故在 `OnEffectApply` 一次性缩放，并用 `_scaled[effIndex]` 防重复叠加。

### 3.3 触发子法术（母体→子）

| 母体 | 子法术（真正伤害） | 缩放落点 |
|---|---|---|
| 奥术飞弹 29955（通道，`PERIODIC_TRIGGER_SPELL`） | **29956**（1260–1540/发） | 缩放 29956 |
| 地狱火灼烧 30859（`PERIODIC_TRIGGER_SPELL`） | **30860**（875–1125/跳） | 缩放 30860 |
| 虚空吐息 38523（`TRIGGER_SPELL`） | **38524**（4163–4837） | 缩放 38524 |
| 虚空领域 37063（`SUMMON`，召唤单位 16697） | 16697 的 SmartAI 施放 **28865 Consumption**（900–1100/2.5s） | 已处理：改 `spell_gen_consumption` 卡拉赞分支 |
| 虚空灼烧 30522（自我光环→30523） | 30523（1200，自身机制） | 不缩放 |

### 3.4 脚本名绑定：`spell_script_names`

`spell_script_names(spell_id, ScriptName)` 把脚本名与法术 ID 关联。**一个脚本名可绑定多个法术**。本方案注册一对脚本类为一个 loader（`RegisterSpellAndAuraScriptPair`），脚本名 `spell_karazhan_direct_scale`，把 32 个法术 ID 全部绑定到它；直接类对 `direct=0` 的法术空转、周期类对无周期光环的法术不触发。

// 直接伤害缩放：命中点重写总伤害。
class spell_karazhan_direct_scale : public SpellScript
{
    PrepareSpellScript(spell_karazhan_direct_scale);

    void HandleDamage()
    {
        if (!GetCaster() || GetCaster()->GetMapId() != KARAZHAN_MAP_ID)
            return;

        auto const it = KarazhanSpellScaling.find(GetSpellInfo()->Id);
        if (it == KarazhanSpellScaling.end() || it->second.direct <= 0.0f)
            return;

        SetHitDamage(int32(GetHitDamage() * it->second.direct));
    }

    void Register() override
    {
        OnHit += SpellHitFn(spell_karazhan_direct_scale::HandleDamage);
    }
};

// DOT 周期伤害缩放：首次真实应用时按倍率重设每跳伤害，避免逐跳叠加。
class spell_karazhan_periodic_scale : public AuraScript
{
    PrepareAuraScript(spell_karazhan_periodic_scale);

    void HandleApply(AuraEffect const* aurEff, AuraEffectHandleModes /*mode*/)
    {
        if (!GetCaster() || GetCaster()->GetMapId() != KARAZHAN_MAP_ID)
            return;

        if (_scaled[aurEff->GetEffIndex()])
            return;

        auto const it = KarazhanSpellScaling.find(GetSpellInfo()->Id);
        if (it == KarazhanSpellScaling.end() || it->second.periodic <= 0.0f)
            return;

        const_cast<AuraEffect*>(aurEff)->SetAmount(int32(aurEff->GetAmount() * it->second.periodic));
        _scaled[aurEff->GetEffIndex()] = true;
    }

    void Register() override
    {
        OnEffectApply += AuraEffectApplyFn(spell_karazhan_periodic_scale::HandleApply, EFFECT_0,
            SPELL_AURA_PERIODIC_DAMAGE, AURA_EFFECT_HANDLE_REAL);
        OnEffectApply += AuraEffectApplyFn(spell_karazhan_periodic_scale::HandleApply, EFFECT_1,
            SPELL_AURA_PERIODIC_DAMAGE, AURA_EFFECT_HANDLE_REAL);
        OnEffectApply += AuraEffectApplyFn(spell_karazhan_periodic_scale::HandleApply, EFFECT_2,
            SPELL_AURA_PERIODIC_DAMAGE, AURA_EFFECT_HANDLE_REAL);
    }

private:
    bool _scaled[3] = { false, false, false };
};

{

## 9. 验证计划

1. **直接伤害核验**：实测憎恨之箭命中 ≈ 13,300–18,000、奥术爆炸 ≈ 31,500–38,500、花环穿圈 ≈ 27,500–32,000，确认与 ICC 10N 招牌/单体量级一致。
2. **DOT 核验**：焦土/灼热吐息每跳 ≈ 6,000–7,900、暗言术痛 ≈ 4,500，确认与血后/教授 DOT 量级一致。
3. **差异化确认**：随机抽 3 个技能，确认倍率**不一致**（如憎恨之箭 3.0× vs 花环爆炸 8.5× vs 小鬼火球 8.0×），验证"非统一倍率"。
4. **触发子法术确认**：奥术飞弹每发 ≈ 4,000–4,900、地狱火灼烧每跳 ≈ 3,500–4,500、虚空吐息 ≈ 12,490–14,510，确认子法术缩放生效。
5. **武器型确认**：顺劈/扫尾伤害仅随 `DamageModifier`（§6.3），未被 C++ 二次放大。
6. **机制完整性**：虚弱/放血/血镜等百分比技能行为与升级前完全一致。
7. **战斗时长**：普通 Boss 4–7 分钟、终局 Boss 6–10 分钟（与上游目标一致）。
