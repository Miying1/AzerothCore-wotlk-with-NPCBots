# 裂隙传送：旧世界5人英雄难度

> 本文档是海加尔山开放区域整体设计方案的子文档，从主文档第八章独立出来。主文档路径：`outputs/巫妖王之怒3.3.5a海加尔山开放区域设计方案.md`

本节设计一种全新的探索与挑战循环：在海加尔山开放地图的固定点位随机生成传送裂隙，玩家组队交互后，随机传入一个旧世界5人副本的英雄难度版本，直接面对强化后的首领。

## 一、设计意图

- 将旧世界经典5人副本重新激活为WotLK满级内容，按三个难度等级递进挑战；
- 地图探索不再是单纯杀怪，也包括"寻找高难度传送裂隙"；T3的红黑裂隙会成为玩家互相通知的热点；
- 随机副本选择和罕见的定点刷新让每次体验都有新鲜感；
- 直接传送到Boss面前，省略清理小怪和跑图的时间；
- T1/T2/T3 分别提供与海加尔山5H/10人/25人内容匹配的装备和材料奖励。

## 二、旧世界副本选择

从经典旧世5人副本中选取部分可重用的副本，每个副本的全部Boss均重新设计为H难度，每次进入随机抽取其中一个Boss：

## 三、裂隙难度分级

裂隙传送共设三个难度等级，从生成率到 Boss 强度逐级递进：

| 等级 | 名称 | 生成权重 | 补充间隔 | 外观 | Boss强度 | 生命倍率 | 伤害倍率 | 掉落等级 |
|---|---:|---|---:|---|---:|---:|---:|---|
| **T1** | 不稳定裂隙 | 65% | 3分钟 | 蓝白色漩涡，偶尔闪烁 | H级（5人英雄难度） | ×1.0 | ×1.0 | 200级紫装 |
| **T2** | 混沌裂隙 | 25% | 8分钟 | 紫色漩涡，带闪电特效 | 强H级（接近10人难度） | ×1.8 | ×1.4 | 226级紫装 |
| **T3** | 深渊裂隙 | 10% | 15分钟 | 红黑色漩涡，地面有裂纹 | 团队级（接近25人难度） | ×3.5 | ×2.0 | 251级紫装 + 稀有掉落 |

同一时间地图上仍最多 **10个** 裂隙对象，但三种难度混合存在：

- T1占大多数，T2偶尔出现，T3极为稀少；
- 每次补充时按权重随机决定新裂隙的难度等级；
- 高难度裂隙在补充后存在更久（T3可存在30分钟），给玩家更多发现和组队时间；
- 三种裂隙使用不同的 GameObject 模型或粒子颜色，让玩家从远处就能辨认。

## 四、传送裂隙关键规则

- 所有难度实例均无冷却时间，同一队伍可反复挑战；
- 玩家无法通过世界地图上的原始副本入口进入，唯一入口在海加尔山的裂隙传送对象；
- 同一 Boss 在三档难度下使用**三个独立 entry**，基础机制相同，但血量、伤害、技能频率和部分新增机制按难度递增；
- Boss奖励使用传统怪物掉落，T1/T2/T3 分别对应不同掉落表。

## 五、传送对象固定点位

在海加尔山全图选取约30个固定坐标作为裂隙传送对象的潜在刷新点：

- 点位均匀分布在灰烬山麓、月井哨站外围、根须裂谷边缘、翡翠回声林、双峰风口和旧军团营地废墟之间；
- 每个点位是坐标固定且区域可见的游戏对象生成位置，例如残破的裂隙石、扭曲的虚空锚、异常的能量漩涡模型；
- 点位之间保持一定距离，避免多个传送对象集中在同一视野；
- 不在月井哨站内部、复活点或任务NPC旁边生成。

## 六、传送对象行为

核心规则：

- 同一时间海加尔山地图上最多存在 **10个** 传送裂隙对象（三种难度混合）；
- T1裂隙每 **3分钟** 自动补充一个，T2每 **8分钟**，T3每 **15分钟**（补充时按权重随机决定难度）；
- T3裂隙生成后存在最多 **30分钟**，T2存在 **15分钟**，T1存在 **10分钟**，超时未使用则自动消失并释放点位；
- 玩家与裂隙对象交互时，弹出对话菜单；
- 菜单内容：显示难度标识、副本名称和首领名称，例如"【深渊裂隙】感知到：死亡矿井·范克里夫之影"，并显示"【进入裂隙】（需要队伍）"选项；T2/T3在菜单中使用不同颜色文字标识难度；
- 玩家必须处于组队状态才能选择进入；
- 玩家选择进入后，裂隙对象消失，不再释放该点位给其他队伍；
- 所有队员被传送到对应副本实例中，直接定位到Boss房间或Boss面前；
- Boss击杀后，队伍成员可通过副本内的传送出口返回海加尔山，或使用炉石/传送法术离开。

## 七、随机选择逻辑

当玩家交互裂隙对象时，难度已由裂隙对象本身的等级决定（T1/T2/T3），服务器只需在该难度下先选定副本，再从该副本的Boss池中随机抽取一位：

- 交互时，服务器随机确定一个旧世界副本，再从该副本的Boss池中随机抽取一位激活；
- 同一个裂隙对象不会连续两次抽到同一个副本+同一个Boss组合；
- 可选池排除队伍中任何成员在最近30分钟内已经通过同难度裂隙击杀过的Boss；
- T2难度Boss的脚本在T1基础上增加额外技能阶段，T3在T2基础上再加机制；Boss的三个entry各自独立掉落表；
- 10个副本 × 3个难度 × 约2.8位Boss/副本 ≈ 84种可抽取组合，提供充分的随机性和逐级挑战。

## 八、实现分层

- **SQL层**：固定点位坐标表、三种难度GameObject模板、Boss三个entry的生物模板及各自 creature_loot_template 掉落表；
- **SmartAI层**：裂隙对象的刷新视觉效果（按难度不同粒子/颜色）、交互Gossip菜单（按难度不同文字颜色）；
- **C++层**：
  - 裂隙传送控制器：管理全局10个上限、按难度权重补充计时（T1=3min/T2=8min/T3=15min）、不同难度超时消失、点位随机选取；
  - 传送逻辑：队伍校验、副本随机选择、副本内随机Boss抽取、按裂隙难度选择对应Boss entry、实例创建、队员全体传送；
  - Boss重设计脚本：同一Boss的三个难度版本共享核心机制脚本，T2增加额外阶段/技能，T3在T2基础上再加机制；各自使用独立生物 entry 和 creature_loot_template；
  - 掉落模板：T1/T2/T3 各自独立的掉落表，全部由SQL管理。

## 九、Boss技能强度提升方法（不改 Spell.dbc）

旧世界 Boss 的技能数值提升到 80 级，不从 Spell.dbc 改值，而是通过以下四种代码手段：

### 方法一：ModifySpellDamageTaken 全局倍数

注册 UnitScript，对该 Boss 的所有法术伤害统一乘系数：

```cpp
void ModifySpellDamageTaken(Unit* target, Unit* attacker, int32& damage, SpellInfo const* spellInfo) override
{
    if (attacker->GetEntry() == NPC_H_VANCLEEF_T3)
        damage *= 2.0;   // T3 深渊难度 ×2
}
```

### 方法二：CastCustomSpell 单独传 BasePoint

不调 DoCast，直接在脚本中用 SPELLVALUE_BASE_POINT0/1/2 覆盖 DBC 基础值：

```cpp
CustomSpellValues values;
values.AddSpellMod(SPELLVALUE_BASE_POINT0, 3500);  // EFFECT_0 = 3500
values.AddSpellMod(SPELLVALUE_RADIUS_MOD, 5000);   // 半径 +50%
me->CastCustomSpell(SPELL_FIREBALL, values, target, TRIGGERED_FULL_MASK);
```

### 方法三：DamageDealt 按技能 ID 分别修正

在 Boss AI 中利用 `me->GetCurrentSpellId()` 判断当前技能，按需乘系数。

### 方法四：SpellScript OnHit 钩子

注册 SpellScript，在 OnHit 时 `SetHitDamage(GetHitDamage() * 倍数)`，不接管原施法脚本。

### 生物属性基线（SQL creature_template）

- `minlevel=82, maxlevel=83` → SelectLevel() 自动按 82/83 级基线计算生命和基础伤害；
- `rank=1`（ELITE）→ _GetHealthMod(1) 和 GetSpellDamageMod(1) 自动乘 rank 系数；
- `DamageModifier=5.0~8.0` → 直接乘在近战伤害上，是调伤害的最快旋钮；
- `unit_class=8`（法师）用于法系 Boss，`unit_class=1`（战士）用于物理 Boss。

## 十一、首期上线范围

- 首批5个旧世界副本（死亡矿井3位、哀嚎洞穴3位、血色军械库1位、血色大教堂1位、祖尔法拉克3位），共11位Boss，每位Boss三档难度共33个entry；
- 30个固定点位，三种GameObject模板，10个同时存在上限；
- 二期补齐剩余5个副本（奥达曼、玛拉顿、通灵学院、斯坦索姆、黑石深渊），共15位Boss，45个entry。
