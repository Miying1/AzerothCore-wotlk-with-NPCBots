# 裂隙BOSS及召唤物技能伤害表（含释放CD与技能描述）

## 最终值口径与计算顺序

- 表内伤害是**单个目标、单次命中或单跳的最终理论值**，按当前数据库 `heroic_dungeon_rift_boss_tier.damage_multiplier`：T1/T2/T3 = 1.0/1.4/2.0。未计护甲、抗性、格挡、减伤、易伤、未命中、暴击、免疫及玩家侧效果。
- 基线优先级：Boss脚本局部 `CastFinalRaidDamageSpell` / `CastRaidTunedSpell` / 自定义 `CastCustomSpell` 覆写 > `rift_spell_damage.h::EffectBasePoints` > DBC原始随机值或模板武器区间。旧接口 `SetRaidSpellDamageMultiplier` 是空实现，**不参与计算**。
- Boss最终值：先确定局部或全局T1基线；再对 `SPELL_DIRECT_DAMAGE` 且 `WeaponDamageMultiplier > 1` 的伤害乘武器倍率；DOT/周期伤害不乘该倍率；最后统一乘Tier倍率。Boss端倍率 `<= 1` 时不额外缩放。
- 召唤物最终值：先确定T1基线或模板武器区间，再乘 `SummonTieredCreature` 的 `spellDamageCoefficient`、Tier倍率；召唤AI的 `SPELL_DIRECT_DAMAGE` 无条件乘 `WeaponDamageMultiplier`，DOT不乘。`RiftLevel70SummonAI` 基准因子为1；60级 `RiftSummonAI` 的历史基准因子15会被 `ScaleRiftSummonSpellDamage` 移除，最终值中不保留15倍。
- 武器/DBC随机伤害以区间给出，公式中的“模板基础区间”沿用本表上版已核定区间，并按当前 `WeaponDamageMultiplier` 重算；固定值行均已按上述顺序展开为T1/T2/T3。

CD口径：优先采用对应裂隙 C++ 脚本中 `ScheduleEvent/RescheduleEvent` 的事件调度；“初始”是进入战斗或阶段后的首次延迟，“重复”是事件重新排队的间隔。它不等同于DBC的RecoveryTime，实际施放可能受读条、事件排队、目标条件和阶段重置影响。召唤物行记录召唤物自身AI的释放周期；无独立法术的召唤物标记为普通攻击/共享近战AI。
