# 世界BOSS 战斗流程与技能说明

> 本文档描述 `src/server/scripts/Custom/WorldBoss/` 目录下全部自定义世界 BOSS 的战斗流程、阶段与技能。
> 所有 BOSS 均为 **83 级**，强度对齐 **10 人冰冠堡垒（ICC 10N）**，用于世界地图随机刷新（普通生物，非召唤物/无 owner），无固定房间坐标。
>
> 公共机制（归属锁定、脱战距离、技能伤害缩放）由基类统一实现，详见文末「公共机制」。

## 奥（Al'ar）

| 项目 | 内容 |
| --- | --- |
| 复刻来源 | 风暴要塞·奥（Eye / TempestKeep） |
| BOSS Entry | `120100` |
| 脚本文件 | `boss_world_alar.cpp` |
| 召唤物 | 奥的余烬 `120500`、烈焰之痕 `120501` |

### 战斗流程（两阶段）

奥为飞行系火鸟，低空盘旋（`SetHover` 悬浮 + 开启追逐移动），全程可被近战攻击。

- **阶段一（PHASE_ONE）**：常规输出阶段。
  - 血量归零时**假死**（不真正死亡）：清空减益、播放死亡动作，保持可选中，6 秒后自动重生进入阶段二。
- **阶段二（PHASE_TWO）**：重生后满血，进入完整技能循环，直至被真正击杀。

## 伊利丹·怒风（Illidan Stormrage）

| 项目 | 内容 |
| --- | --- |
| 复刻来源 | 黑暗神庙·伊利丹（BlackTemple） |

| 召唤物 | 寄生暗影魔 `120502`、阿兹诺斯烈焰 `120504`、暗影魔 `120505` |

### 战斗流程（四阶段）

伊利丹根据血量与阶段自动切换，共四个阶段：

1. **初始阶段（PHASE_INITIAL，100%–65%）**：常规近战输出阶段。
2. **飞行阶段（PHASE_FLYING，65% 血量触发，仅一次）**：原地升空、不可选中，召唤烈焰，远程输出。
3. **着陆阶段（PHASE_LANDING）**：阿兹诺斯烈焰被摧毁后着陆（超时 90 秒强制着陆），恢复近战并追加「痛苦烈焰」；着陆 60 秒后进入恶魔形态。
4. **恶魔阶段（PHASE_DEMON，30% 血量或着陆 60 秒后触发）**：远程输出，60 秒后变回着陆阶段。

## 公共机制

| 机制 | 说明 | 实现位置 |
| --- | --- | --- |
| 归属锁定 | 开战时锁定开怪玩家所在队伍/团队，脱战/死亡后重置 | `WorldBossGuardAI::LockToGroup` / `Unlock` |
| 脱战距离 | 战斗中移动超过 150 码（`WORLD_BOSS_LEASH_RANGE`）即脱战，防止风筝 | `WorldBossGuardAI::CheckLeash` |
| 技能伤害缩放 | 按法术 ID 倍率表统一放大伤害，只对继承基类的自定义 BOSS/召唤物生效 | `BuildWorldBossSpellScaling` / `ScaleWorldBossSpellDamage` |
| 阵营隔离 | 非开怪队伍成员对已锁定 BOSS 视为中立，无法攻击 | `world_boss_reaction_guard`（全局 UnitScript） |
